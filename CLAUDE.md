# Documentation Rule

Every code change must be accompanied by a documentation update.

- New/modified feature → `docs/FEATURES.md`
- New screen, component, store, or hook → directory structure in `docs/ARCHITECTURE.md`
- Database schema change → `docs/DATABASE.md`
- New external integration → `docs/INTEGRATIONS.md`
- New critical rule or constraint → `docs/DEVELOPER_NOTES.md`
- Setup/env/build change → `docs/GETTING_STARTED.md`
- Monetization/paywall change → `docs/MONETIZATION.md`

Do not mark any task complete until the docs are updated.
