## Usage Guidelines

- **Never use shame language.** No "you should," "you must," "don't fail."
- **Never mention gambling or betting in push notification previews.** The app must look like a generic wellness app from the lock screen.
- **Rotate home screen quotes daily** — use the user's local date as a seed so everyone sees the same quote each day (community feel).
- **Relapse quotes must come before any CTA.** Compassion first, always.
- **Milestone quotes are shown once** — on the badge award screen. Not recycled.
